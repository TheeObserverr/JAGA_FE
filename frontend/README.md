# JAGA (Frontend Only Version)

This is the OGP-inspired JAGA application, built as a standalone Next.js app. It includes a mock API layer using Next.js API Routes, making it easy to deploy to Vercel or run locally without a Java backend.

## 🚀 How to Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

3.  **Open App**:
    Visit [http://localhost:3000](http://localhost:3000).

## 🛠️ Deployment

This app is ready for Vercel.
1.  Push this folder to GitHub.
2.  Import the project in Vercel.
3.  Deploy (No custom build command needed, default settings work).

## 📱 Features
- **Singpass-style Login**: Mock authentication flow.
- **Role Switching**: "Sarah" (Caregiver) vs "Uncle Tan" (Senior).
- **Dashboard**: Visualizes JAGA features (Care-Quest, Jiak Ba Buay, JAGA-Link).
